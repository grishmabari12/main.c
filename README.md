# Budget tracker for buying headphones #
## About the project ##
This is my first C programming Project.
The program helps to calculate my monthly expenses and shows how much money is left from my monthly pocket money so I can ensure that wheather
I can buy headphones or not.
## What It Does ##
-Takes monthly pocket money as input.
-Takes food expenses.
-Takes travel expenses.
-Takes college and stationary expenses.
-Takes entertainment expenses.
-Takes other expenses.
-Calculate total expenses.
-Calculates reamining money.
